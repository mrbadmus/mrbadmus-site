Standing conventions in all six:
  - Progress rail ticks only on completed activities, right or wrong.
  - One KEY FACT box per lesson. Amber is reserved for misconceptions.
  - Every lesson names the misconceptions it confronts (see the register).

Stem cells and enzymes are not in this unit. Both were removed by ruling:
stem cells has no KS3 statutory statement, and enzymes moves to the
digestion unit where the programme of study places it.
