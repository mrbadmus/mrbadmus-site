The unit is one argument in five steps: tell a reaction from a change,
see that atoms are rearranged rather than made, write that in words, weigh
it, then write it in symbols and balance it. 05 depends on C2's formulae.

  - One KEY FACT box per lesson. Amber is reserved for misconceptions.
  - Only the mastery ladder marks correctness.
