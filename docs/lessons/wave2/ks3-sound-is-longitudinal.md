**Which line was followed.** NC P32 and Rainford 21a agree. P35 (light against waves in matter) is light's lesson; this page only names light as transverse.

**Gaps and mismatches.** WAVE-16 is "a compression is a place where the air is hotter". In a real sound wave the compressions are very slightly warmer, so "a compression is hotter" is not definitely wrong. The Easy mistakes line is worded "A compression is made by heating the air", which is definitely wrong, and still names the same idea. Examiner please check.
