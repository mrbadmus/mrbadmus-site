**Which line was followed.** NC C17 and Rainford 18a agree. The scheme names hydrochloric acid for the word equations, so the reveal table uses it; sulfuric acid appears once, for naming, because Rung 1 uses it. Nitric acid is left out of this lesson on purpose: with most metals it does not give hydrogen.

**Gaps and mismatches.** The old page taught the reactivity series through an eight-tube bench; the page now gives the order of four metals in one card. The old page's key fact said the hydrogen "comes out of the acid", which is kept. The scheme does not name the reactivity series, but the NC does (C28) and it is the reason copper does not react, which Rung 2 tests.

All four rewritten in one "X, so Y" frame, 11 to 14 words. Key A now "Copper is too unreactive, so it cannot take the hydrogen's place in the acid" (KEY TEXT CHANGED). Key is not the longest.
