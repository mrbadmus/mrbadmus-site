**Which line was followed.** NC C21 and Rainford 18a agree. The scheme puts exothermic and endothermic reactions in one lesson (18a). The site has one page for each, so the endothermic half is on endothermic-reactions, and the temperature data half is shared with measuring-a-temperature-change.

**Gaps and mismatches.** NC C21 says qualitative, so the page has no bond energies and no energy values. "Surroundings" is defined the same way on all three C7 pages: everything around the reacting chemicals, such as the water, the container and the air. The old page's Start here pouch (the reusable hand warmer) is a crystallisation, which is a physical change. Dive deeper says so, and calls it an exothermic change. The disposable iron hand warmer is the reaction example.

These are illustrative classroom values. Compost heap centre about 60 °C.
