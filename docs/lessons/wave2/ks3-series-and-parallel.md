**Which line was followed.** The scheme (22a, 22b, 22c) and the NC (P41, P42) agree. Potential difference is defined as the energy each unit of charge transfers (as on potential-difference); "a push" is only a way to picture it (commander ruling, fix round). The scheme says "voltage"; the page uses potential difference with voltage as the everyday word, and teaches it briefly here because the scheme's 22a and 22b ask for it before this unit's potential-difference page.

**Gaps and mismatches.** The old page taught current and brightness but not what the p.d. does in each arrangement. Rainford 22a and 22b ask for both, so both figures now carry voltmeter readings as well as ammeter readings.
