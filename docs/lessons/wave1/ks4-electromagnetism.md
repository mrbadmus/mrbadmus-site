**Gaps and mismatches.**
- The old page called the electromagnet investigation "RP21". It is not an AQA required practical. Removed.
- The old page never explained WHY a solenoid strengthens the field (the fields of the turns add together inside), which is a spec "explain" skill. Now a card, Rung 2 and Rung 4.
- The old page never described how to demonstrate the magnetic effect of a current (a spec skill); it only named Oersted. Now a card and Rung 2.
- The old page had no Physics-only device-interpretation content for TF/TH. Now the electric bell card with its figure, on TF and TH only.
- Ruling on field-direction rules: the record teaches the right-hand grip rule for the wire and the solenoid, by name (Rainford's SOW key word; mark schemes accept it). Directions checked: thumb along the conventional current, fingers curl the way the field goes; current out of the page gives an anticlockwise field, into the page clockwise; fingers curled with the current round the turns, the thumb points to the north pole end.
- "Number of turns" is not a spec sentence. Kept as "Wind more turns of wire into the same length of coil", which is right as written. (More turns spread over a longer coil would not make the field inside stronger, so the record does not say "more turns" without the same length.)
- Iron rather than steel for the core is not a spec sentence either. It is kept because quiz Q1 (wording kept for its ID) needs it and it follows from the spec's induced-magnet line: the iron core is an induced magnet and loses most or all of its magnetism quickly when the current stops. The card now says steel keeps MORE of its magnetism than iron, so it agrees with Poles of a magnet, which lists steel among the materials that become induced magnets.

**Removed or moved.**
- Removed from CH and TH: the old "higher" box (motor effect, F = BIl, Fleming's left-hand rule, loudspeakers, the generator effect, "Fleming's right-hand rule"). Each has its own lesson; "Fleming's right-hand rule" is not an AQA requirement at all.
- Removed: Oersted (1820), "the field is in a plane perpendicular to the wire", the "anticlockwise end = north" shortcut (the grip rule does the same job, one rule is enough), MRI, maglev, relays and speakers in the applications list. Off-spec, or each needs a diagram the record does not have.
- Moved to Dive deeper: why electromagnets are useful (switch on and off, strength set by the current, the scrapyard crane); the dot-and-cross symbols for current out of and into the page.
- Removed: the matching activity. Its content is in the cards.
- Quiz 1 ("Why is an iron core used in an electromagnet instead of a steel core?"): **question wording kept exactly on every route, so its quiz ID is unchanged**; marked "fixed" because the options and feedback were rewritten. Why: the credited option was visibly the longest, every option had a dash tail, and "soft magnetic material" is not AQA wording and was being served on CF and CH. It now appears on no route. The examiner's distractor "Iron conducts electricity better" was replaced by "Iron makes the current in the coil bigger", because iron does conduct better than steel, so that statement is true even though it is not the reason.
- Quiz 2 ("What happens to the strength of an electromagnet's field when the current is doubled?"): rewritten, new ID, as "…when the current is increased?". The credited answer, "doubles … directly proportional to current", is not on the spec and is not reliably true for an iron-core electromagnet; one distractor ("only the number of turns affects field strength") was built on the same off-spec idea.
- Quiz 3, 4 and 5: new. All four routes now carry the same five questions in the same order.
- Removed from TF and TH: the draft's electric bell question ("In an electric bell, the moving armature breaks the circuit…"). It relied on a bell diagram a quiz item cannot show and named parts (armature, spring, gong) the question never introduced. TF and TH now get the solenoid question CF and CH have ("The magnetic field around a solenoid has a similar shape to the field of which object?"). The bell skill stays taught by the Triple-only bell card.
- New ladder written (2·2·2·1). The ladder is the same on every route, so it does not test the bell. No chain has an alternative order.
