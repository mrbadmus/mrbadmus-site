Spec statements (verbatim, 8463 = 8464): "A system is an object or group of objects. There are changes in the way energy is stored when a system changes. Students should be able to describe all the changes involved in the way energy is stored when a system changes, for common situations. For example: an object projected upwards; a moving object hitting an obstacle; an object accelerated by a constant force; a vehicle slowing down; bringing water to a boil in an electric kettle. Throughout this section on Energy students should be able to calculate the changes in energy involved when a system is changed by: heating; work done by forces; work done when a current flows; use calculations to show on a common scale how the overall energy in a system is redistributed when the system is changed."

The spec does not list the stores or pathways by name; the eight-store / four-pathway vocabulary used here is the standard one in AQA teaching material and is accepted in mark schemes.

## 5. For the lesson author
**Misconceptions seen in AQA marking**: "heat energy" or "electrical energy" named as stores; "energy is used up"; light/sound named as stores; a kettle or battery-lamp chain that skips the pathway; braking "loses" kinetic energy with no destination named.

**Command words**: Describe (the changes in the way energy is stored), Name (the store), Explain.

**Equations**: none. Ek = ½mv² and Ep = mgh ("On the sheet") and Ee = ½ke² (base, "On the sheet") belong to changes-in-energy (6.1.1.2); do not re-teach them here.
