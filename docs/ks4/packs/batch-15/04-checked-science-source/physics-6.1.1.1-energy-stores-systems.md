## Spec core missing from the frozen data (written from the spec, examiner)

8464 6.1.1.1 / 8463 4.1.1.1 (identical): "Students should be able to describe all the changes involved in the way energy is stored when a system changes, for common situations. For example:
• an object projected upwards
• a moving object hitting an obstacle
• an object accelerated by a constant force
• a vehicle slowing down
• bringing water to a boil in an electric kettle."

The frozen data covers the first only (theory 1, q1), the second only in passing ("dropped ball … thermal store (on impact)"), the third and fourth not at all, and gets the fifth wrong (see flag ENERGY-STORES-SYSTEMS-F1). Correct store changes, examiner:
• projected upwards — kinetic store of the object → gravitational potential store (some to thermal store of the surroundings by air resistance).
• moving object hitting an obstacle — kinetic store of the object → thermal stores of the object and obstacle (and surroundings, partly by sound); elastic potential store if it deforms.
• accelerated by a constant force — work done by the force increases the kinetic store of the object (some dissipated to thermal store by friction/air resistance); the store that supplies it depends on the source (e.g. chemical store of fuel, or a pushing person).
• vehicle slowing down — kinetic store of the vehicle → thermal store of the brakes, then of the surroundings (work done by friction).
• electric kettle — energy transferred electrically (work done when a current flows) to the thermal store of the heating element, then by heating to the thermal store of the water; some to the thermal store of the kettle and surroundings.

Spec also, same section: "Throughout this section on Energy students should be able to calculate the changes in energy involved when a system is changed by: heating; work done by forces; work done when a current flows; use calculations to show on a common scale how the overall energy in a system is redistributed when the system is changed." — the calculations are taught in changes-in-energy (6.1.1.2), energy-changes-in-systems (6.1.1.3) and power (6.1.1.4); this lesson needs only the idea of a common scale (total before = total after, shared between stores).

## common_mistake

STORES are where energy is held (kinetic, chemical, thermal etc.). PATHWAYS are how it moves (heating, mechanical work, electrical work, radiation). 'Heat' is a transfer pathway — not a store. You store THERMAL energy, not 'heat'.

## key_note

8 energy stores: kinetic, thermal, chemical, gravitational PE, elastic PE, magnetic, electrostatic, nuclear. 4 pathways: mechanical work, electrical work, heating, radiation. Law of conservation of energy: energy cannot be created or destroyed.
