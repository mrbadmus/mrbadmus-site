## common_mistake

The repeat unit of an addition polymer is NOT the same as the monomer — it's the monomer structure but with the double bond replaced by two single bonds (continuing the chain). To find the monomer from the polymer: take the repeat unit and ADD a C=C double bond between the backbone carbons.

## key_note

Addition polymerisation: alkene monomers + C=C → polymer. One product only, 100% atom economy. Repeat unit in brackets with n subscript. Monomers: ethene → poly(ethene), propene → poly(propene), chloroethene → PVC. Non-biodegradable — environmental problem. Thermoplastics: can be recycled by melting.
