Shell filling

2, 8, 8, then start the fourth.

The first shell holds up to 2 electrons, the second up to 8, the third up to 8 for the first twenty elements. Write the structure as numbers, 2,8,1, or draw it. Choose an element, read its atomic number, then write its structure before you look at the diagram.

Group and period

The structure tells you where it sits.

Elements in the same group have the same number of electrons in their outer shell, which is why they have similar chemical properties. The period is the number of shells in use. This course numbers the groups 1 to 7 and 0: the noble gases have a full outer shell, 8 electrons, except helium with 2.

Key fact

Electrons fill the lowest shell first: 2, 8, 8. Group = electrons in the outer shell. Period = number of shells. Same group, same outer electrons, similar chemistry.
