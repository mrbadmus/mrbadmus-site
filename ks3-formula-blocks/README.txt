TWO FOLDERS, TWO JOBS

  open-these/   Ten lessons as single self-contained files. Double-click any one
                of them. They need no folder around them, no server and no
                connection — every stylesheet, font and script is inside the
                file. This is the version to look at.

  source/       The same ten lessons as .dc.html source, with support.js and
                _ds/ alongside. This is the version Code ports from. These do
                NOT render correctly when opened straight off your disk: the
                page is assembled by script at load, and a browser blocks that
                for a file opened from a folder rather than served. That is why
                open-these/ exists.

  PROMPT-FOR-CODE.md   Hand this to Code. It states the scope constraint first:
                       on the nine existing lessons, ONLY the FIFA formula block
                       changes. Everything else stays as it is.

WHAT CHANGED

  The formula block is now a diagram plus a key, and never an explanation:
  banner in words, "Cover the one you want", one cover button per symbol, the
  figure in colour with the covered cell blacked out, the rearrangement in
  display type, one line on multiply versus divide, then a symbol key of badge +
  quantity name + unit pill.

  Removed everywhere: the sentence per cover state, the paragraph arguing why the
  relationship earns a triangle, and the mono restatement of the formula under
  the diagram. Units moved from a small mono list to pills that cannot be missed.

  p1-08 keeps its beam — a balance of two products is not a triangle. c2-06 and
  c4-04 keep their bars and their cover buttons, because covering a part of a
  part-whole bar is how you get the subtraction.

THE STANDING RULE

  The pattern is now recorded in the project instructions, so every formula block
  built from here follows it without being asked. The reference implementations
  are p5-01 (triangle) and b2-04 (triangle with a balance condition).
