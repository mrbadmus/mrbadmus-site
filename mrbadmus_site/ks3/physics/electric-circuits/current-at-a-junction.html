Electric circuits · System

Current at a junction

Start here

A river splits round an island. Much more water goes down the wide channel. Below the island, the two channels join again.

If you had to guess, how much water flows below the island, compared with above it?

Right. The island stores no water and makes none, so all of it flows on.

It is the same amount. No water is lost, so the channels rejoin with all of it.

Key words

  • A point where a wire splits, or where wires join. It is drawn as a dot.

  • One of the separate paths between two junctions.

  • The wire before the branches split and after they join, carrying the total current.

  • A thousandth of an amp, written mA. 1000 mA = 1 A.

Key knowledge

A junction is a point where a wire splits, or where wires join.

On a circuit diagram, a junction is drawn as a dot.

Charge is not made at a junction, and none is stored there.

So the current going in equals the total current coming out.

A lamp and a resistor are on two branches.

The lamp branch takes 0.30 A. The resistor branch takes 0.20 A.

The main wire carries 0.30 A + 0.20 A = 0.50 A.

current in main wire = current in branch 1 + current in branch 2

With three branches, add all three branch currents.

The current does not always split in half.

Each branch takes its own current.

A branch that is easier to flow through takes more.

It only splits in half when the two branches are identical.

Where the branches split, the main current shares out between them.

Where they join again, the branch currents add back together.

So both ammeters on the main wire read 0.50 A.

No current is left behind in a branch.

The main wire carries 0.45 A. One branch carries 0.15 A. Find the current in the other branch.

  • Convert: nothing. Both readings are in amps.
  • Formula: branch 2 = main wire − branch 1
  • Insert: branch 2 = 0.45 A − 0.15 A
  • Fine-tune: 0.45 − 0.15 = 0.30
  • Answer: branch 2 = 0.30 A

Check: 0.15 A + 0.30 A = 0.45 A, the current in the main wire.

The main wire carries 1.20 A. One branch carries 250 mA. Find the current in the other branch.

  • Convert: 250 mA ÷ 1000 = 0.25 A
  • Formula: branch 2 = main wire − branch 1
  • Insert: branch 2 = 1.20 A − 0.25 A
  • Fine-tune: 1.20 − 0.25 = 0.95
  • Answer: branch 2 = 0.95 A

Take 250 straight from 1.20 and the answer is below zero, which cannot be right.

A new branch does not take current from the other branches.

Each branch still has the battery's full potential difference across it.

So each branch keeps its own current.

The main wire now carries more, and the battery goes flat sooner.

  • Wrong: At a junction, the current always halves.

    Right: It only halves when the two branches are identical.

  • Wrong: A second branch means less current in the first branch.

    Right: The first branch keeps its current. The main wire carries more.

  • Wrong: To find the total, add every reading, including the main wire.

    Right: The main wire reading is already the total of the branches.

  • Wrong: Some current is left behind in the branch that is harder to flow through.

    Right: No current is left behind. It all joins up again after the branches.

  • Wrong: Take 250 mA straight away from 1.20 A.

    Right: Change milliamps to amps first: 250 mA = 0.25 A.

Key fact

At a junction, the current going in equals the total current coming out. The branch currents add up to the current in the main wire.

Rung 1

A junction splits into three branches. The main wire carries 0.85 A, the first branch 0.30 A and the second 0.40 A. What does the third branch carry?

Rung 2

Two lamps are in parallel on a battery, each drawing 0.30 A. A student unscrews one and predicts the other will now draw 0.60 A, because it gets all the current to itself. What is right?

Rung 3

A lamp and a buzzer are in parallel on the same battery. The lamp branch carries 0.30 A and the buzzer branch 0.10 A. Explain what the ammeter in the main wire reads, and why the split is not even.

Rung 4

An extension lead is marked "maximum 13 A". Someone plugs in a heater drawing 9 A, a kettle drawing 11 A and a lamp drawing 0.3 A, and points out that no single appliance is over 13 A. Explain, using the junction rule, why this is dangerous and what will happen.

At A level this rule is called Kirchhoff's first law.

Gustav Kirchhoff wrote it down in 1845.

It comes from a simple fact: charge cannot be made or destroyed.

A kitchen cable carries the kettle, toaster and fridge currents added together.

So the cable and its fuse are chosen for the total current.

Too much current makes a cable overheat.
