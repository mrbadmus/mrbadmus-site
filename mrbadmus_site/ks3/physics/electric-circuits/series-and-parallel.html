Electric circuits · Contrast

Series and parallel

Start here

A bulb blows in the kitchen. The hall light and the fridge carry on working.

If you had to guess, why does the rest of the house stay lit?

Right. Each light is on its own branch, so one broken bulb breaks only that branch.

A fuse box cuts the power when there is a fault. Each light has its own path.

Key words

  • Parts joined one after another in a single loop, with one path for the current.

  • Parts on separate branches, each joined straight across the battery.

  • One of the separate paths in a parallel circuit.

  • The energy each unit of charge transfers, in volts (V). The everyday word is voltage.

Key knowledge

You can join a second lamp in series or in parallel.

In series, the lamps are in one loop, one after the other.

In parallel, each lamp is on its own branch.

To tell which, follow the wire from one end of the battery to the other.

One path means series. A path that splits and joins again means parallel.

Current is measured in amps (A) with an ammeter in the loop.

Potential difference is the energy each unit of charge transfers.

You can picture it as a push.

The everyday word for it is voltage.

It is measured in volts (V) with a voltmeter across a part.

Two identical lamps are in series with a 3.0 V battery.

Both ammeters read 0.15 A. The current is the same everywhere in series.

The battery's potential difference is shared between the lamps.

Each lamp gets 1.5 V, and 1.5 V + 1.5 V = 3.0 V.

The shares always add up to the battery's potential difference.

Each lamp you add in series makes it harder for the current to flow.

So the current gets smaller, and every lamp is dimmer.

One lamp alone on this battery takes 0.30 A. Two in series take 0.15 A.

If one lamp breaks, the only path is broken and both go out.

The same two lamps are in parallel with the 3.0 V battery.

Each branch is joined straight across the battery.

So each lamp gets the full 3.0 V. It is as bright as one lamp alone.

Each branch takes 0.30 A. The current from the battery is 0.60 A.

The branch currents add up to the current in the main wire.

If one lamp breaks, the other branch still works.

Where you meet it

A switch in the main wire turns everything on and off.

A switch on one branch only controls that branch.

That is how each room in a house has its own light switch.

  • Series: join the battery, each lamp in turn, and back to the battery.
  • Parallel: build a loop with the battery and the first lamp.
  • Then join the second lamp with two more wires, across the first lamp.
  • Ammeter: break the loop and put it in the gap.
  • Voltmeter: add it last, with one lead each side of the lamp.

Check the circuit against the diagram before you switch on.

  • Wrong: In parallel, two lamps share one lamp's current, so each is dimmer.

    Right: Each branch gets the full potential difference, so each lamp is fully bright.

  • Wrong: In series, the first lamp gets the current first, so it is brighter.

    Right: The current is the same everywhere, so identical lamps are equally bright.

  • Wrong: Two lamps in series are as bright as one, as the battery is the same.

    Right: In series the current is smaller, so both lamps are dimmer.

  • Wrong: The fuse box keeps the other lights on when a bulb blows.

    Right: Each light has its own branch, so the others keep their path.

  • Wrong: In series, each lamp gets the battery's full potential difference.

    Right: In series it is shared. The shares add up to the battery's value.

Key fact

In series, the current is the same everywhere and the potential difference is shared. In parallel, each branch gets the full potential difference, and the branch currents add up.

Cheap fairy lights are wired in series.

The 230 V mains is shared between many lamps, so each lamp can be small.

Better strings have a tiny wire in each lamp that keeps the loop closed.

Then one broken lamp does not put out the rest.

Every socket and light in a house gets the full 230 V.

So a kettle works the same in any socket, whatever else is on.

The currents in all the branches add up in the main cable.

Adding lamps in parallel also makes a battery go flat sooner.
