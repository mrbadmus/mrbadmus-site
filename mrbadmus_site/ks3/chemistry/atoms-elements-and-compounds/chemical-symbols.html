Key words

  • Symbols and numbers showing the elements in a substance and how many atoms of each.

  • A substance made of only one kind of atom.

  • The table that lists every known element, with its symbol.

Key knowledge

Every element has its own chemical symbol.

Symbols are the same in every language, so nothing needs translating.

Each symbol stands for exactly one element.

Symbols join together to make formulae, like H2O for water.

Every element in the periodic table has a symbol of one or two letters.

The first letter is always a capital.

A second letter is always lower case.

  • C is carbon.
  • Ca is calcium.
  • Co is cobalt.

CO has two capital letters, so it is two symbols, C and O.

It is carbon and oxygen joined: carbon monoxide, a poisonous gas.

Co has one capital letter, so it is one symbol: cobalt, a metal.

Each capital letter starts a new symbol.

A lower case letter belongs to the capital before it.

Count the different symbols to count the elements.

  • NaCl: Na and Cl, so two elements, sodium and chlorine.
  • CaCO3: Ca, C and O, so three elements. The small 3 counts oxygen atoms.

Some symbols come from old Latin names, so they do not match the English name.

Many are metals people have used since ancient times, like gold, iron and lead.

The periodic table lists every known element with its symbol.

Use it to find a symbol, or to find the element a symbol stands for.

Each symbol belongs to one element only.

So a new element needs a symbol that no other element has.

  • Wrong: A symbol is the name shortened, so sodium is So.

    Right: Some symbols come from Latin names. Sodium is Na, from natrium.

  • Wrong: CO and Co mean the same thing.

    Right: CO is carbon and oxygen joined. Co is cobalt.

  • Wrong: Capitals do not matter, so NA is fine for sodium.

    Right: A second letter is always lower case. Sodium is Na.

Key fact

Every element has a symbol of one or two letters. The first letter is a capital, and any second letter is lower case. Each capital letter starts a new symbol.
