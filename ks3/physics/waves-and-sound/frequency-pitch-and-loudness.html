Frequency, pitch and loudness

Start here

Pluck a guitar string gently and listen. Then pluck the same string much harder.

If you had to guess, does plucking harder make the note higher as well as louder?

Right. The note stays where it was. The string swings further, so it sounds louder.

The note stays where it was. A harder pluck only makes the string swing further.

Key words

  • The number of complete vibrations each second, measured in hertz (Hz).

  • How high or low a note sounds. A higher frequency gives a higher pitch.

  • How far the vibrating source moves from its rest position each time.

  • How loud a sound is. A bigger amplitude gives a louder sound.

Key knowledge

Frequency is the number of complete vibrations each second.

It is measured in hertz, Hz.

1 Hz is one complete vibration each second.

A string that vibrates 440 times each second has a frequency of 440 Hz.

A microphone and an oscilloscope can show a sound as a trace like these.

A taller wave has a bigger amplitude, so it sounds louder.

More waves across the screen means a higher frequency, so a higher pitch.

Turning the volume up makes a loudspeaker cone move further each time.

It still vibrates the same number of times each second.

So the sound gets louder, and the pitch stays the same.

All sounds travel at the same speed through air, about 340 m/s.

A higher frequency sound has a shorter wavelength.

Its compressions are closer together, because more are made each second.

number of vibrations = frequency (Hz) × time (s)

frequency (Hz) = number of vibrations ÷ time (s)

The number of vibrations is a count, so it has no unit.

Time must be in seconds, because 1 Hz is one vibration each second.

A tuning fork of frequency 200 Hz rings for 3.0 s. Find how many complete vibrations it makes.

  • Convert: nothing. The time is already in seconds.
  • Formula: number of vibrations = frequency × time
  • Insert: number of vibrations = 200 Hz × 3.0 s
  • Fine-tune: 200 × 3.0 = 600
  • Answer: 600 vibrations

A tuning fork makes 15 000 vibrations in 0.50 minutes. Find its frequency.

  • Convert: 0.50 min × 60 = 30 s
  • Formula: frequency = number of vibrations ÷ time
  • Insert: frequency = 15 000 ÷ 30 s
  • Fine-tune: 15 000 ÷ 30 = 500
  • Answer: frequency = 500 Hz

Divide by 0.50 instead of 30, and the answer is sixty times too big.

  • Wrong: A loud note is a high note.

    Right: Loudness depends on the amplitude. Pitch depends on the frequency.

  • Wrong: A higher note travels faster.

    Right: All sounds travel at the same speed through the same material.

  • Wrong: Turning the volume up adds vibrations each second.

    Right: Turning it up makes each vibration bigger. The frequency stays the same.

  • Wrong: A hertz measures how loud something is.

    Right: A hertz measures frequency. 1 Hz is one vibration each second.

  • Wrong: Put 0.50 minutes straight into the equation.

    Right: Change minutes to seconds first. 0.50 min × 60 = 30 s.

Key fact

Frequency is the number of vibrations each second, measured in hertz (Hz). A higher frequency gives a higher pitch, and a bigger amplitude gives a louder sound.

Loudness is measured in decibels, dB.

A whisper is about 30 dB. Normal talking is about 60 dB.
